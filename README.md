# MOBILAND — сайт сервисного центра в Конаеве

Статический сайт для Hoster.kz (Plesk). Готовые файлы: `index.html`, папка `assets/` и страницы перенаправлений `about.html`, `services.html`, `location.html`.

## Редактирование

- Тексты, услуги и контакты: `index.html`.
- Исходный CSS: `src/site.css`. Готовый CSS: `assets/site.css`.
- Меню, фильтры, график и подготовка сообщения: `assets/site.js`.
- После изменения CSS или utility-классов в HTML: `npm install`, затем `npm run build`.
- Для локального просмотра: `python3 -m http.server 8765 --bind 127.0.0.1`.

Готовый сайт не требует Node.js на хостинге. CSS и SVG-иконки локальные; внешние библиотеки оформления не загружаются.

## Поведение

Форма подготавливает текст и открывает WhatsApp. Сообщение отправляет посетитель. Форма не хранит введённые данные. Публичные цены и ориентиры сроков ремонта удалены. Стоимость и срок мастер определяет после диагностики, до начала ремонта.

График рассчитывается в `Asia/Almaty`: Пн–Пт 10:00–14:00 и 15:00–19:00; Сб по договорённости; Вс выходной. График и гарантия до 6 месяцев подтверждены владельцем 09.10.2026.

Яндекс.Метрика `99598032` и Google Analytics `G-X9DQZZ01GW` включаются на `mobileland.kz`, `www.mobileland.kz` и `lemonramis.github.io`. На localhost счётчики не загружаются. Клики по телефону и WhatsApp фиксируются как `contact_click` в GA и `contact_phone` / `contact_whatsapp` в Метрике; содержимое формы в эти события не передаётся.

Кнопки карт выполняют поиск адреса; точная карточка бизнеса и вход пока не подтверждены. Отзывы следует добавить после получения подлинных источников. `style.css` сохранён как прежний файл; новый лендинг использует `assets/site.css`.

Основной адрес: https://mobileland.kz/. robots.txt и sitemap.xml используют этот адрес. Публикуются только HTML, assets, robots.txt, sitemap.xml и .htaccess; исходники CSS и инструменты сборки остаются локально. Перенаправление HTTP → HTTPS включается в Plesk после выпуска сертификата.

## Публикация в Plesk

Репозиторий: `https://github.com/LemonRamis/MobiLand.git`. Plesk использует ветку `deploy/mobileland-kz`, ручное развёртывание в `/httpdocs`. После правок и локальной сборки перенесите только 10 публичных файлов в эту ветку, отправьте её в GitHub, затем в Plesk выполните «Получить обновления», «Развернуть сейчас». Ветка `main` сохраняет исходники и инструменты сборки. HTTPS и его перенаправление уже включены в Plesk; сертификат Let’s Encrypt автоматически продлевается.
